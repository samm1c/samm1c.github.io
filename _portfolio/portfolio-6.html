a web application modeled after Pomofocus

personal project

Pomofocus is a site I used frequently throughout college to help me study - pretty much everyday. I liked how simple it was, but there were a few problems I consistently ran into, so I decided to create my own. For example, I changed how the tracker looked and removed a few settings to reduce clutter.

stack: MERN (MongoDB, Express, React, Node.js), JavaScript
